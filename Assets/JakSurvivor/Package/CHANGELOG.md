# 0.1.0

First release.

- Added Jak as a survivor, available immediately, using Jak 3's original model, textures, animations, effects and sounds.
- Added Blaster and Arc Wielder primaries; Scatter Gun, Wave Concussor and Spin Attack secondaries; and Dodge Roll and Jet-Board utilities.
- Added the Dark Jak special, which swaps in Dark Claws, Dark Bomb and Dark Blast for ten seconds.
- Added a survivor-select entrance with Jak's Dark Jak transformation and Morph Gun twirl.
- Added item displays for Jak's model.
