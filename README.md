# Jak Survivor

![Jak in Risk of Rain 2](https://raw.githubusercontent.com/MahmoudHilani/ROR2-Jak-Survivor/main/docs/media/hero.gif)

- Adds Jak from Jak 3 as a playable survivor, available immediately
- Uses Jak 3's original model, animations, effects and sounds
- Daxter rides along on Jak's shoulder and joins him on the Jet-Board
- Switches between Morph Gun combat and a timed Dark Jak transformation
- Has nine skills, including Arc Wielder, Wave Concussor, Spin Attack and Jet-Board alternates
- Multiplayer compatible (all players need the same version)
- Doesn't replace any survivor
